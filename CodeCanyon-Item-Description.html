Architecture overview

Why CognitixERP?

  • Modular monolith — clear module boundaries with a single deployable API
  • Modern .NET stack — .NET 10, Blazor WASM UI, ASP.NET Core API
  • Beautiful MudBlazor UI — responsive, permission-gated pages
  • Multi-database Setup Wizard — SQL Server, PostgreSQL, MySQL (buyer-friendly install)
  • Multi-branch & multi-currency ready for real businesses
  • Licensing included — trial / license enforcement for marketplace deployments
  • Optional biometric agent — Windows HRM attendance agent

Technology Stack

  • Frontend: Blazor WebAssembly + MudBlazor
  • Backend: ASP.NET Core API (Controllers, Middleware, SignalR)
  • Architecture: Clean Architecture per module (Domain / Application / Infrastructure)
  • Databases: SQL Server · PostgreSQL · MySQL
  • Cross-cutting: Shared DTOs, Localization, FileStorage, Notifications, SyncContracts
  • Optional: Cognitix.BiometricAgent (Windows)

What’s Included

  • Full source for WebApp + API + business modules
  • Buyer documentation (Installation, Production, FAQ, Developer Guide, User Manual)
  • Setup Wizard for first-time configuration
  • Licensing DLLs for marketplace builds
  • Optional deploy samples (e.g. same-origin nginx / VPS)

Modules Overview

1. Billing Module

Manage and automate your billing process with tools designed for precision, efficiency, and customer satisfaction.

  • Dashboard — quickly view billing performance metrics
  • Quotations — generate and manage customer quotes
  • Orders — track and process customer orders
  • Invoices — create and manage customer invoices
  • Customer receipts — digitally issue receipts to customers

2. Procurement Module

Streamline your procurement process with effective tools for supplier management and purchasing.

  • Suppliers — manage supplier information
  • Quotations — request and compare quotes
  • Orders — create and track purchase orders
  • Invoices — record and verify supplier invoices
  • Supplier payments — process payments efficiently

3. Inventory Module

Manage inventory efficiently with comprehensive tools and insights.

  • Dashboard — stock and performance overview
  • Products — product master with images, SKU, barcode
  • Product Groups / Brands / Categories — structured catalog
  • Discount Types — flexible discount configuration
  • Units of Measure — base & sales UoM support
  • Warranty Claims — claim tracking
  • Inventory Analytics & Aging — insights and aging alerts

4. POS Module

Optimize retail and sales operations with powerful POS features for seamless transactions and reporting.

  • POS Terminal — efficient and intuitive sales interface
  • Sales History — detailed sales transaction logs
  • POS Sessions — open / close / monitor cashier sessions
  • Coupons — create and apply promotional discounts
  • POS Settings — customize terminal preferences

5. Financials Module

Manage your financial operations with accuracy, control, and real-time insights.

  • Dashboard — financial KPIs at a glance
  • Chart of Accounts — structured ledger accounts
  • Journal Entry & Opening Balance — full bookkeeping control
  • Fiscal Years — period management
  • Payment Methods & Payment Journals
  • Expenses & Cost Centers
  • Currency Management — exchange rates, revaluation, observability
  • Method Routing Matrix & GL Account Mappings

6. Banking Module

Streamline your banking operations with secure, accurate, and intelligent tools.

  • Dashboard — banking overview and analytics
  • Accounts — manage bank accounts
  • Transactions — incoming / outgoing movement
  • Cheques — cheque management
  • Transfer — account-to-account transfers
  • Import Statements — CSV / statement import
  • Reconciliation — match books with bank statements
  • Ledger — banking ledger view

7. CRM Module

Improve customer relationships and sales performance with a complete CRM toolkit.

  • Dashboard — CRM insights & analytics
  • Contacts / Leads / Customers — full relationship lifecycle
  • Opportunities & Sales Pipeline — visualize deal flow
  • Sales Teams & Activities — calls, tasks, team performance
  • Lost Reasons & Conversion Dashboard — learn from wins and losses
  • Pipeline Settings & Duplicate Detection
  • Automation — workflow automation
  • Tickets — support & service
  • Sales Forecasts — predict revenue

8. HRM Module

Complete human resource management — from organization structure to payroll and exit processes.

  • Dashboard — HR insights & analytics
  • Organization Chart — hierarchy visualization
  • Appraisals & Employee Goals / Skills
  • Departments, Designations & Contracts
  • Attendance — daily attendance & kiosk
  • Shifts & Rotations — schedules and assignments
  • Late Entry & Regularization
  • Leave Management — applications & leave types
  • Payroll & Benefits — salary processing, overtime
  • Loans & Advances
  • Resignations & Terminations — exit / compliance tracking
  • Approval Workflows — automated approvals
  • Optional Biometric Agent — Windows-based attendance capture

9. Branching Module

Configure company profile, branding, and multi-branch operations with clear organizational control.

  • Company Setup — company profile wizard
  • Branding — logo and favicon
  • Branches — multi-branch management
  • Isolation — branch-level access control
  • Company View — company details overview

10. Users Module

Secure authentication, roles, permissions, and audit for enterprise access control.

  • Login & Auth — JWT secure sign-in
  • User Management — create and manage users
  • Roles — role definitions
  • Permissions — page and action access
  • User Profile — personal settings and photo
  • Audit Viewer — security activity logs

11. Compliance Module

Regional tax and e-invoice compliance profiles, reports, and audit trails.

  • E-Invoice — compliance profiles
  • ZATCA Reports — Saudi e-invoicing reports
  • GST Reports — GST compliance reporting
  • NBR Reports — regional tax reporting
  • Audit Trail — e-invoice audit history
